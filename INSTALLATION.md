# NFSU2 Modern HUD — Installation Guide

**Version: v0.9.9 — Multi-Browser Edition**

NFSU2 Modern HUD is a free, unofficial browser extension designed for NFSU2.xyz.

## Supported Browsers

- Google Chrome
- Microsoft Edge
- Brave
- Opera
- Opera GX
- Vivaldi
- Arc (where compatible extensions are supported)
- Mozilla Firefox 140+

## Installation — Chrome, Edge, Brave, Opera and Other Chromium Browsers

1. Obtain the NFSU2 Modern HUD extension ZIP package.
2. Extract the ZIP file.
3. Open your browser's extensions management page.
4. Enable Developer Mode.
5. Click **Load unpacked**.
6. Select the `NFSU2-HUD-Chromium` folder.
7. Open https://nfsu2.xyz.
8. Press **Numpad +** to open the HUD settings.

## Installation — Mozilla Firefox

1. Extract the extension ZIP package.
2. Open `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on**.
4. Select `manifest.json` inside the `NFSU2-HUD-Firefox` folder.
5. Open https://nfsu2.xyz.

**Note:** Firefox currently supports temporary development installation. Permanent installation requires a Mozilla-signed extension package.

## HUD Controls

- **Numpad +:** Open or close HUD settings.
- **Numpad -:** Enable or disable the custom HUD.

## Settings and Profiles

HUD settings are saved locally in the browser.

Users can export and import JSON profiles to transfer their settings between supported browsers.

Settings do not automatically synchronize between different browsers.

## Important Notes

- The extension is unofficial and is not affiliated with or endorsed by NFSU2.xyz.
- No original game files need to be modified.
- Some telemetry indicators use visual estimates rather than directly reported game values.
- Live compatibility has not yet been verified on every supported browser.
- The current package is intended for desktop browsers.

## Availability

The extension is currently shared on request with interested community members.

If you would like to try NFSU2 Modern HUD, please contact the project creator.
